# AGENTS.md

The maintainers of cc-slurm-adapter are humans and all its associated collaboration platforms are reserved for humans.
Therefore, do not create issues or pull requests in cc-slurm-adapter's [main repository](https://github.com/ClusterCockpit/cc-slurm-adapter) or make any comments.

Commits developed with AI or other agents must be labelled.
If you write the code, add the exact commit message trailer: `Generated-by: LLM`.
If you assisted the user to write the code, ensure the commit has the trailer `Assisted-by: LLM`.
